# Fonts

Bundled so that building the app needs no network. Each file is the Latin
subset of the variable font, as served by Google Fonts, unmodified.

| File | Typeface | Licence |
|---|---|---|
| `newsreader-latin.woff2`, `newsreader-italic-latin.woff2` | Newsreader | SIL Open Font License 1.1 |
| `work-sans-latin.woff2` | Work Sans | SIL Open Font License 1.1 |
| `space-grotesk-latin.woff2` | Space Grotesk | SIL Open Font License 1.1 |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | SIL Open Font License 1.1 |

Characters outside the Latin subset fall back to the system font.
